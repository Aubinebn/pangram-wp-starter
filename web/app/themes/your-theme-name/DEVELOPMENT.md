# Développer le thème

Ce thème est construit avec **[Sage](https://roots.io/sage/)**. Pour le fonctionnement de Sage (templates Blade, View Composers, composants, Tailwind CSS, Vite, `theme.json`…), référez-vous à sa documentation :

- [Documentation Sage](https://roots.io/sage/docs/)
- [Documentation Acorn](https://roots.io/acorn/docs/) (composants Laravel dans WordPress, commandes `wp acorn`)
- [Blade (Laravel)](https://laravel.com/docs/blade) et [Tailwind CSS](https://tailwindcss.com/docs)

Ce guide ne couvre que ce qui est propre au theme. Pour installer le projet, voir le [README à la racine du projet](../../../../README.md).
